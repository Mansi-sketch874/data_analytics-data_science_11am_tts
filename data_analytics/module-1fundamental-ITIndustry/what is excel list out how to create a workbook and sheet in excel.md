# What Is Microsoft Excel?

Microsoft Excel is a spreadsheet application used to enter, organize, calculate, analyze, and present data. It stores information in rows and columns and provides tools such as formulas, charts, tables, sorting, filtering, and pivot tables.

## Important Excel Terms

- **Workbook:** An Excel file. It usually has the `.xlsx` extension.
- **Worksheet or sheet:** A page inside a workbook made of rows and columns.
- **Cell:** The box where a row and column meet, such as `A1`.
- **Row:** A horizontal line identified by numbers.
- **Column:** A vertical line identified by letters.
- **Range:** A group of cells, such as `A1:C10`.
- **Formula:** An expression used to calculate a result, such as `=SUM(A1:A10)`.

## How to Create a New Workbook

1. Open Microsoft Excel.
2. Select **Blank workbook** on the start screen.
3. Excel opens a new workbook with a default worksheet.
4. Enter data into the cells.
5. Select **File > Save As**.
6. Choose a folder, enter a file name, and select **Save**.

### Create a Workbook from an Existing Template

1. Open Excel.
2. Select **New**.
3. Choose a template, such as a budget, calendar, or invoice.
4. Select **Create**.
5. Replace the sample information with your own data.
6. Save the workbook with a suitable name.

## How to Add a New Sheet

1. Open the workbook.
2. Select the **plus (+)** button beside the sheet tabs at the bottom.
3. A new worksheet is added.

Another method is to right-click an existing sheet tab, select **Insert**, choose **Worksheet**, and select **OK**.

## How to Rename a Sheet

1. Double-click the sheet tab.
2. Type a meaningful name, such as `Sales Data`.
3. Press **Enter**.

You can also right-click the tab, select **Rename**, type the name, and press **Enter**.

## How to Delete, Move, or Copy a Sheet

- **Delete:** Right-click the sheet tab and select **Delete**.
- **Move:** Drag the sheet tab to a new position.
- **Copy:** Right-click the tab, select **Move or Copy**, select **Create a copy**, and choose **OK**.

## How to Format a Sheet

1. Select the cells to format.
2. Use the **Home** tab to change the font, size, color, alignment, or number format.
3. Use **Format as Table** when the data has headings and should be filtered.
4. Adjust column widths and row heights so the data is easy to read.

## How Excel Helps in Data Analytics

Excel is commonly used to:

- clean and organize data;
- calculate totals, averages, percentages, and trends;
- sort and filter records;
- create charts and dashboards;
- summarize data with PivotTables;
- import and export data from other applications;
- prepare reports for business decisions.

## Good Practices

- Give each sheet a clear name.
- Use the first row for column headings.
- Keep one type of information in each column.
- Avoid blank rows inside a data table.
- Save work regularly and keep backup copies.
- Use formulas instead of manually repeating calculations.
- Check numbers, dates, and spelling before creating reports.
