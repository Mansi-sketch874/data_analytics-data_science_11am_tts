# What is URL?

URL stands for Uniform Resource Locator. It is the address used to access a resource on the internet, such as a webpage, image, file, or document.

In simple words, a URL tells the browser where a particular resource is located on the web.

Example:
https://www.google.com

This is a URL that points to the Google homepage.

---

## Parts of a URL

A URL generally has the following parts:

### 1. Protocol
It tells the browser how to access the resource.

Examples:
- http://
- https://
- ftp://

### 2. Domain Name
It is the website name or host name.

Example:
www.google.com

### 3. Subdomain
Optional part before the main domain.

Example:
mail.google.com

### 4. Path
It shows the location of a specific page or file on the website.

Example:
https://www.example.com/products/laptop

### 5. Query String
It contains additional parameters or values.

Example:
https://www.example.com/search?q=analytics

### 6. Fragment
It points to a specific section within a page.

Example:
https://www.example.com/about#team

---

## Importance of URL

- Helps users access websites
- Identifies a resource on the internet
- Enables navigation between web pages
- Helps browsers and servers communicate

---

## Types of URL

### 1. Absolute URL
An absolute URL contains the full web address including protocol, domain, and path.

Example:
https://www.example.com/index.html

Used when the full location of the resource is needed.

---

### 2. Relative URL
A relative URL is a partial path that is relative to the current page or website.

Example:
/about.html
/images/logo.png

Used inside the same website or web application.

---

### 3. Static URL
A static URL does not change and usually points to a fixed webpage or file.

Example:
https://www.example.com/about-us

Used for content that remains constant.

---

### 4. Dynamic URL
A dynamic URL contains parameters and often changes based on user input or database values.

Example:
https://www.example.com/products?id=101&category=laptop

Used in search pages, filters, and database-driven websites.

---

### 5. HTTPS URL
An HTTPS URL uses the HyperText Transfer Protocol Secure (HTTPS) encryption.

Example:
https://www.bankofamerica.com

Used for secure communication and online transactions.

---

### 6. HTTP URL
An HTTP URL uses the normal HyperText Transfer Protocol and is not encrypted.

Example:
http://www.example.com

Used in non-secure websites.

---

### 7. FTP URL
An FTP URL is used for transferring files between computers over the internet.

Example:
ftp://ftp.example.com/files

Used for downloading or uploading files.

---

### 8. Mailto URL
A mailto URL opens the user’s email application to send an email.

Example:
mailto:info@example.com

Used for contact links.

---

### 9. Tel URL
A tel URL is used to open a phone dialer for calling a number.

Example:
tel:+123456789

Used for click-to-call links.

---

### 10. File URL
A file URL points to a local file on a computer or network.

Example:
file:///C:/Users/Desktop/report.pdf

Used for local computer files.

---

### 11. Canonical URL
A canonical URL tells search engines which version of a page is the preferred one when duplicates exist.

Example:
https://www.example.com/page

Used in SEO to avoid duplicate content issues.

---

### 12. Short URL
A short URL is a shortened version of a long URL.

Example:
https://bit.ly/abc123

Used for social media, marketing, and easy sharing.

---

### 13. Broken URL
A broken URL is a URL that does not work because the page or resource no longer exists.

Example:
https://www.example.com/old-page

Used to indicate missing or invalid resources.

---

## URL Examples by Type

- Website URL: https://www.google.com
- Search URL: https://www.google.com/search?q=data+analytics
- Image URL: https://example.com/images/logo.png
- PDF URL: https://example.com/files/report.pdf
- Contact URL: mailto:info@example.com

---

## Difference Between URL and Domain Name

- Domain name is only the website name such as google.com
- URL is the full address including protocol and path such as https://www.google.com/search

---

## Conclusion

A URL is the address used to locate resources on the internet. It helps browsers access websites, files, images, and other online content. There are many types of URLs, including absolute, relative, static, dynamic, HTTP, HTTPS, FTP, mailto, tel, and file URLs, each serving different purposes.

---

## Short Exam Answer

A URL (Uniform Resource Locator) is the internet address of a resource. It is used to access websites and files online. Different types of URLs include absolute URL, relative URL, static URL, dynamic URL, HTTP URL, HTTPS URL, FTP URL, mailto URL, tel URL, file URL, and short URL.
